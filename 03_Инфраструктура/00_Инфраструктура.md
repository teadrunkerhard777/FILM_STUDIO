# Организация документации

Каждый раздел проекта представляет собой самостоятельный модуль документации.

Внутри каждого раздела главным документом является файл `00_<Название>.md`.

Именно с него начинается изучение раздела.

Все остальные документы служат дополнением, развитием или журналом изменений главного документа.

Пример:

00_Основание_проекта/
├── 00_Основание.md
├── 01_Изменения.md
├── 02_Термины.md
└── 03_Вопросы.md

01_Манифест_студии/
├── 00_Манифест.md

03_Инфраструктура/
├── 00_Инфраструктура.md
