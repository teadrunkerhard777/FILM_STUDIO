# Карточка оценки книги-кандидата

## Назначение карточки

Карточка используется для последовательной оценки произведения перед передачей в производство книгофильма. Оценка начинается с поиска уже существующих экранизаций, пересказов и других аудиовизуальных воплощений книги. Только после этого проводится подробный анализ произведения.

Она не заменяет внимательного анализа книги и не сводит решение к числовому рейтингу. По каждому направлению необходимо зафиксировать вывод, его основания, обнаруженные риски и вопросы, требующие дополнительной проверки.

### Варианты оценки

- **Соответствует** — существенных препятствий не обнаружено.
- **Соответствует с оговорками** — книга подходит, но имеются управляемые сложности или риски.
- **Не соответствует** — обнаружено препятствие, несовместимое с принципами книгофильма.
- **Требует проверки** — информации пока недостаточно для обоснованного вывода.
